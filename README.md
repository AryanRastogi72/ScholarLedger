# ScholarLedger

ScholarLedger is a blockchain-based academic credentialing system built for the CSD436 midsem project. It addresses two major gaps in existing systems:
1. **Identity-Spoofing Vulnerability (Security)**: Cryptographically binds institutional identity to an on-chain issuer key, preventing the forgery attack outlined by Zonneveld et al. (2026).
2. **Batch Processing Bottleneck (Concurrency)**: Implements an Optimistic Concurrency Control (OCC) execution scheme inspired by Block-STM to execute non-conflicting credential transactions in parallel.

## Prerequisites
- Node.js (v18 or higher recommended)
- MetaMask browser extension

## Setup & Running the Project

The project is split into three components: Hardhat (Smart Contracts), Batch Service (OCC Engine API), and Frontend (React DApp). You will need **three separate terminal windows** to run this locally.

### Terminal 1: Hardhat Local Node & Contracts
```bash
cd ScholarLedger
npm install

# Start the local Hardhat node
npx hardhat node
```
*Keep this terminal running. It provides the local blockchain at `http://127.0.0.1:8545`.*

In a new terminal window (Terminal 1b), deploy the contracts:
```bash
cd ScholarLedger
npx hardhat run scripts/deploy.js --network localhost
```

### Terminal 2: OCC Batch Service
```bash
cd ScholarLedger/batch-service
npm install

# Start the Express server
node server.js
```
*Keep this terminal running. The API will be available at `http://localhost:3001`.*

### Terminal 3: React Frontend
```bash
cd ScholarLedger/frontend
npm install

# Start the Vite development server
npm run dev
```
*Keep this terminal running. The app will be available at `http://localhost:3000`.*

## Setting up MetaMask for Localhost
1. Open MetaMask and go to **Settings > Networks > Add Network > Add a network manually**.
2. Network Name: `Hardhat Localhost`
3. New RPC URL: `http://127.0.0.1:8545`
4. Chain ID: `31337`
5. Currency Symbol: `GO` or `ETH`
6. Save and switch to this network.
7. To interact with the DApp, import one of the private keys generated by `npx hardhat node` into MetaMask. The first account is the `admin` who can register institutions.

## Features to Demo
- **Register Institution**: Using the admin account, register an institution to authorize it.
- **Forgery Demo**: Head to `/demo` to show how ScholarLedger blocks unregistered spoofed issuers compared to legacy hash-only systems.
- **Issue / Verify / Revoke**: Standard credential lifecycle.
- **Batch Issue**: Upload a CSV or enter multiple records manually to see the OCC engine parallelize non-conflicting transactions and serialize conflicts.
